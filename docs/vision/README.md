# Vision Documents

This directory contains vision and pitch materials for the Paper-Data Linking project.

## Files

- `vision_infographic.html` - Single-page infographic showcasing the project's capabilities and roadmap

## Public Link

The infographic is hosted via GitHub Gist for easy sharing:

**https://htmlpreview.github.io/?https://gist.githubusercontent.com/abuonomo/690df784e681fb07dfc5318246e47d2b/raw/vision_infographic.html**

## Updating the Public Version

After making changes to `vision_infographic.html`, update the gist:

```bash
gh gist edit 690df784e681fb07dfc5318246e47d2b -a docs/vision/vision_infographic.html
```

Or update via the web interface at:
https://gist.github.com/abuonomo/690df784e681fb07dfc5318246e47d2b
