AI-Powered Science Discovery for Heliophysics

The Vision

Published science is hard to find and harder to reproduce. We extract what was actually studied (instruments, time ranges, methods, phenomena) and link every paper to downloadable data. Today this works for instrument and time extraction. With funding, we extend to methods and phenomena, enabling synthesis across the literature: summarize all research using a given dataset, identify understudied events, track how techniques evolve.

Proven Foundation

Production system extracting dataset claims (instrument + time range) from papers:

  • Public search interface, internal validation tool, REST API
  • Integrates with ADS, VSO, and CDAWeb
  • Generates Python snippets to download referenced datasets
  • LLM evaluation framework
